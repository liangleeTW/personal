## Local Preview

This is a GitHub Pages project site, so generated assets use `/personal/...` paths. Local preview should serve the built site under `/personal/` as well.

### 1. Build

From this repo:

```bash
uv run build.py build -f
```

The build output is written to `_site/`.

### 2. Mount `_site` At `/personal/`

Run from this repo:

```bash
mkdir -p /tmp/personal-preview
rm -f /tmp/personal-preview/personal
ln -s "$PWD/_site" /tmp/personal-preview/personal
```

Check the mount:

```bash
ls -la /tmp/personal-preview
```

You should see something like:

```txt
personal -> .../_site
```

### 3. Start The Server

```bash
cd /tmp/personal-preview
python3 -m http.server 8000
```

Then open:

```txt
http://localhost:8000/personal/
```
or 

```bash
uv run build.py preview
```

## Generated Files

The `_site/` directory is generated by the build and is ignored by Git. 
To clean generated output:

```bash
uv run build.py clean
```
